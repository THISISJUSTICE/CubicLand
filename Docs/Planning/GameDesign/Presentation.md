# 렌더링

게임의 시각 표현과 이를 보여주기 위한 카메라 방향을 정리한다.

---

## 그래픽 방향

비주얼은 비교적 단순한 Cube 기반 스타일을 사용한다.

고해상도 캐릭터 모델이나 복잡한 스켈레탈 애니메이션보다는 다음 요소를 활용한다.

- Cube Mesh
- Material
- Point Light
- 필요할 경우 Directional Light나 이를 대체할 후처리 효과 고려
- Particle System
- Shader
- Transform Animation
- 물리 움직임
- Cube 파괴 연출
- 자체 발광 Core
- 간단한 Trail 또는 Projectile Effect

애니메이션은 Transform과 물리적인 움직임을 적극 활용한다.

TrailRenderer와 LineRenderer는 시점에 따라 얇은 면처럼 보일 수 있으므로 필수 기술로 사용하지 않는다.

투사체 이동 표현에는 Particle 기반 연출도 고려한다.

화면에 다수의 골렘과 Cube가 동시에 존재할 수 있으므로 그래픽과 연출의 성능을 설계할 때 모바일 환경도 함께 고려한다.

### Cube의 시각 정보

Cube의 외형은 골렘의 상태를 전달하는 정보로 사용한다.

- 스탯이 높아질수록 RGB 색상은 흰색에서 검은색에 가까워진다.
- Core에서 자식 방향으로 멀어질수록 색상은 다시 흰색에 가까워진다.
- 일반 Object Cube는 알파를 1로 유지하고 HP가 감소할수록 Crack을 강하게 표시한다.
- Core는 전용 알파 표현과 중앙의 PointLight를 사용한다.
- Object Cube는 Core를 완전히 가릴 수 있으며, Core를 보이게 하기 위해 주변 파츠를 투명하게 만들지 않는다.
- Skill Cube의 투명도는 일반 Cube와 별도의 시각 규칙을 사용한다.

## 카메라

3인칭 카메라를 기본으로 고려한다.

기본 카메라는 다음 기능을 제공한다.

- 플레이어 추적
- 기본 카메라 회전
- 플레이어와 카메라 사이의 벽 가림
- 최소한의 FOV 설정

추가로 고려할 기능은 다음과 같다.

- 맵 경계 처리
- 전방 및 후방 시점 전환
- 조준 카메라
- 스킬 사용 시 카메라 연출
- 골렘 크기 변화에 따른 거리 조절
